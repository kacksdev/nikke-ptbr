# Contribuição

Este é um repositório de pesquisa pública, não um repositório de mod.

## Contribuições aceitas

- Link para política ou documentação oficial relevante.
- Correção factual na análise publicada.
- Observação técnica não invasiva e reproduzível.
- Sugestão de clareza ou acessibilidade na documentação.

## Conteúdo proibido

- Assets, textos integrais, bancos, bundles ou executáveis do jogo.
- Credenciais, tokens, IDs de conta, logs pessoais ou dados de terceiros.
- Código de injeção, bypass, interceptação, automação de gameplay ou anti-cheat.
- Links para ferramentas ou pacotes que prometam contornar proteção.
- Afirmação de autorização sem fonte oficial verificável.

Use Issues. Pull requests não alteram o repositório sem análise e aceite explícito de `@kacksdev`; a branch principal é protegida e exige o proprietário como responsável.
