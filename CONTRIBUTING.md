# Contribuição

Este repositório acompanha publicamente o desenvolvimento do NIKKE PT-BR. O plugin, o catálogo e as builds permanecerão privados enquanto o mod estiver em produção.

## Contribuições aceitas

- Correção de informação técnica ou documental.
- Sugestão de ferramenta compatível com a arquitetura do mod.
- Melhoria de clareza, acessibilidade ou organização.
- Relato sobre terminologia que possa ser útil ao futuro glossário.

## Conteúdo que não deve ser publicado

- Assets, bancos, bundles, executáveis ou textos integrais do jogo.
- Credenciais, tokens, IDs de conta, logs pessoais ou dados de terceiros.
- Builds privadas, links para pacotes fechados ou conteúdo fora do escopo de localização.

Use Issues para propostas. Pull requests não alteram o repositório sem análise e aceite explícito de `@kacksdev`; a branch principal é protegida e Kacks mantém a decisão final sobre o projeto.
