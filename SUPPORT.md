# Suporte

- Para instalar, verificar, reparar ou remover, consulte [`docs/INSTALACAO.md`](./docs/INSTALACAO.md).
- Para confirmar a versão testada, consulte [`docs/COMPATIBILIDADE.md`](./docs/COMPATIBILIDADE.md).
- Para o estado e os limites conhecidos, consulte [`docs/STATUS.md`](./docs/STATUS.md).
- Para erros reproduzíveis, abra uma [Issue](https://github.com/kacksdev/nikke-ptbr/issues/new/choose).
- Para vulnerabilidades, use o [relato privado](https://github.com/kacksdev/nikke-ptbr/security/advisories/new).

Inclua sempre as versões do mod e do cliente, a tela afetada e o comportamento observado. Não envie dados de conta, credenciais, saves, dumps, textos integrais ou arquivos proprietários do jogo.
