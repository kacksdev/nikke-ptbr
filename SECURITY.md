# Segurança

## Escopo

O repositório contém somente documentação e imagens. Não há mod, executável, DLL, catálogo, texto extraído, workflow de build ou mecanismo que interaja com o cliente.

## Relato privado

Para credencial exposta, dado pessoal, link indevido ou outro problema de segurança desta documentação, use o [relato privado de vulnerabilidade](https://github.com/kacksdev/nikke-ptbr/security/advisories/new) em vez de abrir uma Issue pública.

## Fora do escopo

- Falhas do cliente, servidores ou contas de NIKKE.
- Pesquisa de vulnerabilidade, datamining ou engenharia reversa do jogo.
- Solicitação de acesso a builds ou arquivos que não existem neste repositório.
- Contorno de autenticação, anti-cheat, integridade ou proteção tecnológica.

Problemas com o produto devem ser encaminhados aos canais oficiais.
