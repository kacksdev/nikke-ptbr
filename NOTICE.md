# Aviso do projeto

GODDESS OF VICTORY: NIKKE, personagens, marcas, nomes, músicas e conteúdos
pertencem aos respectivos titulares. O NIKKE PT-BR é um projeto comunitário
independente, gratuito e sem afiliação, patrocínio ou endosso oficial.

Os recursos monocromáticos deste repositório servem à identificação visual do
projeto. Nenhum banco extraído, texto original integral, executável ou asset do
cliente é distribuído aqui.

O repositório ainda não contém uma versão instalável. Quando houver release, o
pacote deverá incluir somente componentes produzidos pelo projeto e o mínimo
necessário para aplicar a tradução sem redistribuir o jogo.
