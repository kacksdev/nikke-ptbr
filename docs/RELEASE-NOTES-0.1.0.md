A primeira versão funcional do NIKKE PT-BR entrega uma tradução comunitária gratuita de ampla cobertura para GODDESS OF VICTORY: NIKKE no PC.

## Compatibilidade

- Cliente validado: `NIKKE.PC_Official_GL_151.8.5`
- Plataforma: Windows x64
- Versões futuras desconhecidas são recusadas sem alteração do cliente.

## Download e integridade

- Instalador: `NIKKEPTBRv0.1.0.exe`
- Tamanho: 44.595.712 bytes
- SHA-256: `F1EB0CEB91A88F6EC23CC6B48A0376FA04B8BCC42FB8F9A0BD2962FCD7EEB444`

O arquivo `.sha256` e o manifesto JSON publicados junto ao instalador permitem conferir a identidade exata da versão.

## Cobertura

- 429.498 unidades únicas com base PT-BR
- 536.489 ocorrências conhecidas
- 34 tabelas de origem
- 2.743 modelos de texto formatado
- zero bloqueio estrutural pendente

Esta é uma beta funcional de ampla cobertura, não uma revisão editorial integral. Existem 1.689 apontamentos exclusivamente editoriais preservados para uma possível revisão futura.

## Segurança e validação

A instalação adiciona somente três componentes próprios e não substitui arquivos oficiais. O pacote passou por 18/18 provas, o executável final por 11/11 e a suíte atual por 116/116. Duas construções finais consecutivas foram idênticas.

A carga útil exata foi aceita no cliente real, com instalação, runtime, reparo, remoção e rollback aprovados. O invólucro final foi recompilado depois apenas para congelar a reprodutibilidade e completar avisos de licenciamento, mantendo pacote, bootstrap e núcleo do instalador idênticos.

O executável não possui assinatura digital comercial. O Windows pode exibir um aviso do SmartScreen.
